# Network Architectures (Mermaid)

Ce dépôt contient des schémas d’architectures réseaux OT/IT réalisés en **Markdown + Mermaid**.

## Objectif
Fournir des représentations **simples, exactes et sécurisées** pour :
- Accès distant (Remote Access)
- Collecte et transfert de données (Data)

## Standards
- IEC 62443 (zones & conduites)
- Directive NIS 2 (cybersécurité OT/IT)

## Organisation
- `/docs/remote-access` → variantes accès distant (Ewon, VPN client, hybride)
- `/docs/data` → variantes collecte données (Ewon datalogger, myClaugerDetect, SCADA)
- `/templates` → légende, checklist sécurité, modèle générique

## Usage
- Les fichiers `.md` contiennent directement le code **Mermaid**.
- Visualisation possible via GitHub, VSCode (extension Mermaid), ou [Mermaid Live Editor](https://mermaid.live).
